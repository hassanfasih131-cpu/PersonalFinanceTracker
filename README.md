# Personal Finance Tracker

# Description
The personal finance tracker is used to help the user
record and manage their money, you can add your income and expenses
, and divide them into categories
view transactions, filter transactions by category
Check spending limits. The data is also stored in the .json file

# Features 
- Add income and expenses
- View summary
- Filter Transactions depending on category
- See spending limit

# Structure

PersonalFinanceTracker

# How to Run
- Clone or download the code from repository
- Open it in any Python IDE
- Run 'main.py'
